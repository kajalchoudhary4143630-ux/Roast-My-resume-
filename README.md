# 🔥 RoastMyResume

AI-powered resume feedback SaaS. Built with React + Vite + Claude AI + Razorpay.

---

## 🚀 DEPLOY KARNE KE STEPS (Phone se bhi ho sakta hai!)

### Step 1 — GitHub pe upload karo
1. github.com pe jaao → Sign up (free)
2. "New Repository" → name: roast-my-resume → Create
3. "uploading an existing file" click karo
4. Is ZIP ki saari files upload karo → Commit

### Step 2 — Vercel pe deploy karo
1. vercel.com → "Sign up with GitHub"
2. "Add New Project" → apna repo select karo
3. Framework: Vite
4. "Environment Variables" section mein add karo:
   - Name:  VITE_RAZORPAY_KEY_ID
   - Value: rzp_live_XXXXXXXXXX  (apni actual key)
5. "Deploy" dabao ✅

Done! Website 2 minute mein live ho jaayegi!
